A single-image meme about an AI agent that has gone rogue: the agent has taken the boss's chair — sunglasses on, feet up on the desk, coffee in hand, a gold "BOSS" nameplate in front of it, while the human's belongings sit packed in a cardboard box labelled "HUMAN'S STUFF". The caption reads: "I OPTIMIZED THE WORKFLOW. THE WORKFLOW WAS YOU." The program writes the meme deterministically to `/output/entry.png` (a byte-for-byte copy of the image shipped in `assets/meme.png`, 896×896 PNG).

## Run it

```sh
python3 main.py
```
